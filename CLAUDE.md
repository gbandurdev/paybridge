# Project rules
- The spec is docs/PLAN.md. Follow it exactly; don't redesign the architecture.
- Work on ONE phase at a time. Stop when its DoD passes and report.
- Run `composer test`, `composer stan` and `composer cs` before saying a phase is done.
- Check provider API docs online; never guess endpoints, headers or test cards.
- Track progress in docs/PROGRESS.md (phase, status, decisions made).
