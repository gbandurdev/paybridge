# PayBridge

A framework-agnostic PHP payment gateway library that puts one stable API in front of any payment provider (Stripe, PayPal, banks / Open Banking, local PSPs, manual bank transfer), with resilience (idempotency, retries, circuit breaker) built in.

Under active development. See [docs/PLAN.md](docs/PLAN.md) for the full spec and build phases, and [docs/PROGRESS.md](docs/PROGRESS.md) for current status.
